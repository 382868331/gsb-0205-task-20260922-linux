# haplophase — 跨片段二倍体单倍型定相（B&B）

纯 Python 标准库实现的可复用定相题库：给定二元杂合位点与带缺失、带正整数
翻转代价的跨片段读段，求互补单倍型对 `(h, 1-h)`，使“每条读段分配给翻转
代价较低一方”后的总翻转代价最小。核心是**全局分支界限（branch & bound）**，
不是逐位独立投票。

- Python 版本：**Python 3.14.7**（仅用标准库；3.10+ 的语法亦可运行）
- 第三方依赖：**无**。安装 Python 后无需 `pip install` 任何东西。
- 离线：核心、测试、演示全部离线运行，不访问网络 / 账号 / 数据库 / 云 API。

## 问题与记号

- 位点数 `n_loci`（1..18，位点编号 1..n_loci），读段数 1..200。
- 读段在若干位点上给出 0/1 观测（`AlleleCall(locus, allele, flip_cost)`），
  未列出的位点视为**缺失**；空读段表示全缺失读段。
- 每个观测带**正整数**翻转代价。
- 对候选单倍型 `h`，读段 `r` 分给 `h` 的代价 = 与 `h` 不一致观测的代价和，
  分给 `1-h` 的代价 = 与 `h` 一致观测的代价和（二者之和为该读段总权重）。
  读段取两者较小值；目标
  `f(h) = Σ_r min( 分配给 h 的代价, 分配给 1-h 的代价 )`。
- `(h, 1-h)` 与 `(1-h, h)` 是同一个互补对，故**固定 `h[0] = 0`** 消除对称，
  枚举空间为 `2^(n_loci-1)`。

## 公开接口

```python
from haplophase import AlleleCall, phase_haplotypes

result = phase_haplotypes(reads, *, n_loci=18, node_budget=10_000_000)
```

- `reads`：1..200 条读段的可迭代对象；每条是 `AlleleCall` 的可迭代对象。
- `n_loci`：关键字参数，1..18（默认 18）。
- `node_budget`：关键字参数，B&B 节点预算（正整数，默认 10^7）。最优层与
  次优层在**同一次** DFS 中求出，共享该预算。

`PhasingResult` 字段（全部为不可冻结的只读 dataclass / 元组）：

| 字段 | 含义 |
| --- | --- |
| `h` | 最优代表单倍型（`h[0]==0`），0/1 元组 |
| `complement` | `1-h` |
| `optimal_cost` | 最优总翻转代价（整数，精确） |
| `is_unique` | 最优 h 是否唯一 |
| `all_optimal_h` | 全部并列最优 h（按 h 字典序）；断连组件常导致多个 |
| `second_best_h` / `second_best_cost` | 次优的“不同 h”。**多最优时为另一个同代价最优（`gap=0`，直接刻画歧义）；唯一最优时为严格下一层（`gap>0`）；`n_loci=1` 候选唯一时为 `None`** |
| `gap` | `second_best_cost - optimal_cost`（非负整数） |
| `assignments` | 每读段 `ReadAssignment(index, assigned, cost_to_h0, cost_to_h1, flipped_loci)`；`assigned` 为 0（给 h）/1（给 1-h）/`None`（并列） |
| `modified_positions` | `(读段下标, 1基位点)` 元组：所有非并列读段需要翻转的位置 |
| `search` | 搜索状态：预算、已用节点、位点分支顺序、访问 / 叶 / 剪枝 / 在任更新计数、是否完成 |

## 输入上限（接口边界）

- `n_loci`：1..18；`locus`：1..n_loci；读段数：1..200。
- `allele`：0 或 1；`flip_cost`：正整数。
- 同一读段内不允许同一位点重复观测。
- 上限是硬边界，超出抛错（不是“尽量算”）。短演示不穷举上限规模。

## 错误语义

- 任何非法输入抛 `haplophase.InvalidInputError`（同时是 `ValueError`），
  错误消息带可定位前缀，如 `reads[3][1].flip_cost ...`，**不静默纠正**。
  - 数值输入拒绝 `NaN` / `+Infinity` / `-Infinity`；
  - 所有整数参数（含 `n_loci`、`node_budget`、`AlleleCall` 字段）拒绝
    `bool`（Python 中 `True/False` 虽是 `int` 子类，这里明确拒绝）；
  - 浮点即使是整数值（如 `2.0`）也按整数域契约拒绝。
- 搜索预算耗尽抛 `haplophase.SearchBudgetExhausted`，**与非法输入、与
  “证明无解”严格分开**。本问题在合法输入下枚举空间非空、恒有可行解，
  因此不存在“无解”；预算耗尽时不返回任何未经证明的“最优”，异常对象只
  附带中断时的在任值（incumbent，不保证最优）与部分搜索状态供诊断。
- 接口为无状态纯函数：非法输入在任何搜索开始前抛出，不存在部分变更。

## 算法与设计取舍

1. **单遍 B&B 同时求最优层与次优层。** DFS 在每个节点维护部分前缀下每条
   读段“已匹配权重 `m`、剩余权重 `rem`、总权重 `W`”。读段最终代价
   `min(m, W-m)` 是关于 `m` 的凹函数，在可行区间 `[m, m+rem]` 上的最小值
   在端点取得，故读段的可证下界贡献为
   `min(m, W-m, m+rem, W-m-rem)`；对读段求和为节点下界，叶子处恰为真实
   代价（无松弛间隙）。
2. **保留前两个不同代价层。** 只有当节点下界严格大于已知次优值 `S` 时才
   剪枝；`S` 未找到前不剪枝。因此最优、全部并列最优与次优都是**经证明的
   精确值**，不是估计。代价等于层值的子树也保留，以便登记同代价中字典序
   最小的 h。
3. **互补对称**：位点 1 在深度 0 固定为 0，不产生二分支。
4. **分支顺序**：自由位点按该位总观测代价降序；每个二分支优先沿贪心在任
   解取值探索，使上界尽早收紧。两者只改变访问顺序，不改变枚举完整性。
5. **贪心初始上界**：确定性坐标下降（全 0 起点 + 前缀贪心起点）给一个可行
   h 作在任解，纯粹用于提前剪枝；不参与结果正确性。
6. **常量读段归约**：只有 0/1 个观测的读段（含全缺失读段）对 `f(h)` 恒贡献
   0（总能分给完全匹配的一方），不参与搜索，但仍出现在 `assignments` 中。
7. 全部用 Python 任意精度整数，**无浮点运算**。

### 为什么不是逐位投票 / MEC 贪心

位点经读段耦合：一条跨多位点的读段必须整体分给某一方，逐位独立计票会破坏
这种全局一致性。本实现枚举全部 `2^(n_loci-1)` 个相位（受下界剪枝），在
18 位、200 读段的接口边界内精确求解。

## 数值 / 误差口径

- 所有输入代价与全部中间量、输出均为**整数**，运算为精确整数运算，
  **不存在舍入误差、不需要任何容差（tolerance）**。
- 唯一的浮点相关行为是**拒绝** `NaN`/`Infinity` 浮点输入；模块不产生浮点
  结果，故 README 无需（也不提供）浮点误差界限。
- 代价理论上界：≤ 200 读段 × 18 位 × 单观测代价；Python 整数无溢出。

## 可复现 / 确定性

- 无随机数、无全局可变状态、无时间依赖；相同输入任意次调用结果逐字段相同
  （测试 `test_determinism_across_calls` 覆盖）。
- 并列最优与同代价次优统一按 h 元组字典序（位点 1 优先）确定代表，输出稳定。
- 演示数据由 `demo.py` 内的固定字面量 / 固定种子生成，不依赖外部附件或网络。

## 已知限制（按本题契约的数学子集）

- 仅支持二元等位（0/1）、正整数翻转代价、最多 18 位点 / 200 读段；不实现
  多等位基因、连续置信度、读段配对 / barcode、概率或群体单倍型参考等，
  **不宣称兼容任何行业标准格式或完整单倍型定相协议**。
- 目标固定为“每读段整体二选一的最小翻转代价”，不建模读段内部分配、
  测序错误率或拷贝数。
- 18 位最坏情形（如 200 条全长、强矛盾读段）下界较松，完整证明约需
  数千万节点、纯 Python 下可能达到十余秒；可通过提高 `node_budget`
  完成（预算耗尽会明确报错而不是给假答案）。常规稀疏跨片段数据为亚秒级。
